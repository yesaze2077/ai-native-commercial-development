## 已关闭发现

| 原问题 | 原负向复现 | 最终修复与复验 |
|---|---|---|
| EOF 后不再监测 deadline | 子进程关闭 stdout/stderr 后 sleep(.35)，timeout=.05，初版错误 passed 并可缓存 | 输出 EOF 后继续监测进程；最终超时失败、不产生成功证据 |
| 解析 symlink 后改变虚拟环境入口 | venv/bin/python 直接运行 prefix 正确，经初版 runner 变为系统 Python 并失败 | 实际执行保留配置入口，散列 resolved 目标；最终 venv prefix 正确并可按声明复用 |
| 自定义缓存写入 Git refs | cache-dir=.git/refs/heads/verification-cache 初版 passed，随后 git show-ref exit128 | Git/private/common 目录仅放行本 worktree 专用 namespace；主仓及 linked worktree 负向用例均拒绝、无写入且 Git 正常 |
| 外置/无基线 profile 变更漏全量选择 | 修改 external profile 的未受选 other 命令为 exit9，初版仍仅选 lib/app 并 passed | 对外置、基线缺 blob 或 blob 内容不一致给保守升级，选全当前层并禁缓存；最终 other 实跑失败，计划模式仍无执行 |

ignored 修复复核：tracked+非 ignored untracked 仍参与变化；普通 node_modules/venv/测试输出不成为 unknown、也不引起指纹自失效；显式 ignored test/runtime/global 输入仍可纳入指纹；无关 ignored 目录按 glob 前缀剪枝。新增 elapsed_seconds 区分总耗时与命令耗时。
