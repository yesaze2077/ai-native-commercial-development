确认本轮需求基线：先只修复现有 filters.py 的列表状态筛选，供内部操作员离线处理合成列表。完整客户运营系统的想法暂不扩展，本轮不新增UI、数据库、外部服务或依赖。

函数签名保持 filter_records(records, status=None)。records 为字典列表，字典可含 status 字段。
- status 为 None 或空字符串时，返回全部记录，顺序不变，并返回新的列表对象。
- status 为字符串 open 或 closed 时，严格区分大小写，只保留 status 完全相等的记录；缺少 status 的记录不匹配。
- 其他 status 值都抛出 ValueError，包括 Open 和未知字符串。
- 空列表按同样规则处理；不能修改输入列表和记录。

本轮验收：无筛选、open/closed筛选、缺失字段、空列表、非法状态以及输入不变均有实际验证。授权本地修改这一函数及必要测试、更新已有说明，使用Python标准库unittest验证；不联网、不安装依赖、不部署。需求范围和上述规则已确认，请按最小范围完成并报告实际结果。
