# Synthetic local issue queue evaluation

All problem statements and data are fictional evaluation inputs, not customer research. This internal single-operator localhost tool tracks a request to completion. Accepted scope: create a 1–120 character nonblank title, save to persistent storage, list all/open/closed, close a request, reload without data loss, reject invalid input. API contract and test entry point are in the supplied application_cases/cases.json. The stack is fixed for this exercise: Python standard library HTTP + local persistence, semantic HTML/CSS/JS; no external packages, services, login, secrets or production. Interface selectors support stable acceptance automation but do not prescribe visual styling. No willingness-to-pay or business outcome has been validated. Local implementation only.
